# UOR Offline Foundry Console — Integration Boundaries & Architecture

## 1. Five-Layer Architecture

1. **Studio Presentation (`src/components/*`, `src/components/studio/*`, `src/components/views/*`)**
   - Renders Chat, Preview, Build, Verify & Release, and Advanced views.
   - Displays explicit mode and status tags (`DEMO`, `LOCAL`, `ONLINE`, `NOT CONNECTED`, `NOT VERIFIED`, `RELEASE BLOCKED`).
2. **Project, Conversation & Durable Local Services (`src/services/foundryService.ts`, `src/services/durableLocalStore.ts`, `src/services/syncService.ts`)**
   - Manages projects, conversation sessions, approval-gated drafts, and revisioned `DurableOperation` records.
   - Persists browser-local workspace caches in IndexedDB (`uor_foundry_durable_v1`) with backward-compatible `localStorage` fallback (`uor_foundry_console_state_v2`).
   - Browser storage is strictly a local workspace cache—never an authoritative project database or proof store.
   - Air-gapped exports (`uor.foundry.air-gapped-bundle.v2`) use strict deny-by-default allowlisting, require an export preview + explicit operator confirmation, omit chat bodies/credentials/raw artifacts/local paths/unknown properties, explicitly label bundles as unencrypted and unsigned (`UNENCRYPTED_UNSIGNED_METADATA_ONLY`), and keep imports disabled.
3. **AI & Preview Adapters (`src/adapters/chatProviderAdapter.ts`, `src/adapters/artifactPreviewAdapter.ts`, `src/adapters/windmillAdapter.ts`)**
   - `ChatProviderAdapter`: Async interface with `AbortSignal` cancellation, preview element references, and approval-gated proposals (`MockPreviewChatProvider` in preview; `WindmillLmStudioChatProvider` fail-closed contract).
   - `ArtifactPreviewAdapter`: Supports `ui-build`, `document`, `json-artifact`, `workflow-output`, `image-diagram`, and `validation-report`, with explicit `DEMO`, `DRAFT`, `BUILT`, `VERIFIED`, and `UNAVAILABLE` states and sandbox separation.
4. **Windmill Execution Services & `.raw_app` Packaging (`src/adapters/windmillExecutionService.ts`, `uor_foundry.raw_app/`)**
   - Targets workspace `uor-offline-foundry` at `http://127.0.0.1:8080`.
   - Supports Option A (`VITE_AUTHENTICATED_LOCAL_PROXY`) and Option B (`uor_foundry.raw_app/` Windmill-native full-code app using `wmill.ts` generated by `wmill app dev`).
   - Windmill CLI packaging status inside AI Studio: `PREPARED / NOT VERIFIED`.
5. **Independent Engineering Verification & Release Authority (`src/services/verificationAuthorityService.ts`, `VerificationView.tsx`, `ApprovalsView.tsx`)**
   - Uses versioned policies (`VERIFICATION_POLICIES`) defining mandatory authorities and minimum suite versions per `productFamily`, defaulting to `NOT VERIFIED` when no policy is established.
   - Rejects simulated `PASS` results, duplicate authority claims, stale versions, mismatched digests/revisions, and unauthenticated browser records.
   - Requires explicit `APPROVED_FOR_RELEASE` (`PRODUCTION_RELEASE` scope) bound to exact project ID, artifact SHA-256 digest, source revision, policy version, required evidence references, timestamp, and independently authenticated human approver identity. `APPROVED_FOR_TEST_SIMULATION` never satisfies production release.
